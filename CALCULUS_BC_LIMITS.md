## Overview
This slideshow contains comprehensive Free Response Question (FRQ) practice problems for AP Calculus BC limits, complete with detailed solutions.

## Study Tips

1. **Try each problem yourself first** before looking at the solution
2. **Show all work** - AP graders award partial credit
3. **Justify your steps** - state which theorems or properties you're using
4. **Check for indeterminate forms** before applying L'Hôpital's Rule
5. **Practice mental math** for simple limits to save time

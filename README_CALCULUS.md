# AP Calculus BC - Limits FRQ Practice

## 🎓 Overview

A comprehensive Free Response Question (FRQ) practice resource for AP Calculus BC limits, built as an interactive reveal.js slideshow presentation.

## 📚 What's Included

### 🎯 Interactive Slideshow (21 slides)
- **8 Complete FRQ Problems** with detailed solutions
- **Practice Tips** and strategies
- **Common Mistakes** to avoid
- **Reference Sheet** with essential formulas

### 📖 Study Materials
- **[CALCULUS_BC_LIMITS.md](CALCULUS_BC_LIMITS.md)** - Complete guide and instructions
- **[QUICK_REFERENCE.md](QUICK_REFERENCE.md)** - Quick reference guide with formulas
- **[PRACTICE_WORKSHEET.md](PRACTICE_WORKSHEET.md)** - 18 practice problems
- **[ANSWER_KEY.md](ANSWER_KEY.md)** - Complete solutions to worksheet
- **[PROJECT_SUMMARY.md](PROJECT_SUMMARY.md)** - Project overview

## 🚀 Quick Start

### View the Slideshow

**Option 1: Using Jekyll (Recommended)**
```bash
bundle install
bundle exec jekyll serve
```
Then open your browser to `http://localhost:4000`

**Option 2: GitHub Pages**
1. Push to GitHub
2. Enable GitHub Pages in repository settings
3. Access via your GitHub Pages URL

**Option 3: Read Directly**
All slides are in the `_posts/` directory as Markdown files

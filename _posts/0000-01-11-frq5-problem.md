## FRQ 5: Piecewise Function Continuity

**Problem:**

Consider the piecewise function:

$$f(x) = \begin{cases} 
\frac{x^2 - 4}{x - 2} & \text{if } x < 2 \\
ax + b & \text{if } x \geq 2
\end{cases}$$

**(a)** Find $\lim_{x \to 2^-} f(x)$.

**(b)** For what values of a and b is f(x) continuous at x = 2?

**(c)** If a = 3, find the value of b that makes f(x) continuous at x = 2.
